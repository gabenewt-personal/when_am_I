# When Am I? — Prototype starter pack

Hand this folder to Claude Code and say: **"Read CLAUDE_CODE_BRIEF.md, CONTENT_GUIDE.md, DATA_SOURCES.md and the JSON files in data/. Build the playable MVP described in the brief. Maintain the Rare Encounter retro 8-bit arcade aesthetic. Preserve the written clues and use the attached scenarios as fixtures."**

Files:
- `CLAUDE_CODE_BRIEF.md` — product/engineering instructions and acceptance tests.
- `CONTENT_GUIDE.md` — storytelling standards and quality checklist.
- `DATA_SOURCES.md` — authoritative sources, licenses, and future content-ingestion plan.
- `data/categories.json` — category-bound, canonical answer pools and aliases.
- `data/scenarios.json` — seven authored daily mysteries with six clues, epilogues, anchors, sources and art guidance.

These are prototype assets, not a complete production content calendar. The scenarios should be editorially fact-checked and play-tested before a public launch. The first release intentionally needs no paid API keys, external database, AI service, or proprietary images.

This revision emphasizes the familiar Rare Encounter visual style and clarifies that *no live data API is necessary for the initial seven-scenario prototype*.
